# 🎵 Web-Based Music Player

A responsive and interactive web-based music player built using **HTML, CSS, and JavaScript**.
It allows users to play, pause, and manage songs with real-time progress tracking and modern UI controls.

---

## 🚀 Features

* ▶️ Play / Pause functionality
* ⏭️ Next / Previous track controls
* 🔁 Repeat (single & playlist) modes
* 🔀 Shuffle playback support
* 📊 Real-time progress bar with seek control
* ⏱️ Current time and total duration display
* 🎨 Clean and responsive user interface
* 🎧 Dynamic song loading from playlist

---

## 🛠️ Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling and layout
* **JavaScript (Vanilla JS)** – Functionality and interactivity

---

## 📁 Project Structure

```
📦 Web-Based-Music-Player
 ┣ 📜 index.html
 ┣ 📜 style.css
 ┣ 📜 inscript.js
 ┣ 📜 musiclist.js
 ┣ 📁 assets (songs & images)
```

---

## ⚙️ How It Works

* Songs and metadata are stored in `musiclist.js`
* JavaScript dynamically loads song details (name, artist, image, audio)
* Audio controls are managed using the HTML5 `<audio>` element
* Event listeners handle user interactions like play, pause, skip, and seek
* Progress bar updates in real-time based on audio playback
